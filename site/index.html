讓終端機，
開口說話。

$ say -i "讓終端機，開口說話。"

say 是跨平台的文字轉語音指令，用法和 macOS 內建的 say 一樣。Windows、Linux、macOS 都能執行，內建 300 多種 Microsoft Edge 神經語音，也不需要另外安裝 ffmpeg。

$ npm install -g @willh/say

需要 Node.js 18 以上，安裝時會核對執行檔的 SHA-256。沒有 Node.js？改用一行指令安裝。

安裝 say

沒有 Node.js 的話，用一行指令安裝；已經裝了 Node.js，也可以用 npm。兩種方式都會下載對應系統、預先編譯好的執行檔並核對 SHA-256，電腦上不需要 Rust，也不需要 ffmpeg。

  • macOS 與 Linux $ curl -fsSL https://say.gh.miniasp.com/install.sh | sh
  • Windows（PowerShell） PS> irm https://say.gh.miniasp.com/install.ps1 | iex

預設裝在 ~/.local/bin。Windows 會自動把它加進 PATH；macOS 與 Linux 如果還沒加，腳本會印出要加的那一行。想裝到別處，先設定 SAY_INSTALL_DIR。

$ npm install -g @willh/say
$ say "你好世界"
$ npx @willh/say "你好，這是跨平台的 say！"
# Linux 要先裝 ALSA 開發標頭
$ sudo apt-get install -y libasound2-dev pkg-config
$ cargo install --git https://github.com/doggy8088/say

每個版本都附上六個平台的壓縮檔和 .sha256 校驗檔。解壓縮後，把 say 放進 PATH 裡的任一個資料夾就能用。

常用指令

從最簡單的一句話，到建置完成時出聲提醒你。

念一段文字

多個參數會用空白接起來；什麼都不給的話，就逐行念出你打的字，按 Ctrl+D 結束。

$ say "早安，今天天氣真好！"
$ say Hello from cross-platform say

建置完成時出聲提醒

把 say 接在長時間的指令後面，就不用一直盯著畫面。

$ npm run build && say "建置完成" || say "建置失敗"
$ git log -1 --pretty=%s | say

換一種聲音

完整名稱或名稱片段都可以。用環境變數 SAY_VOICE 可以改掉預設語音。

$ say -v YunJhe "歡迎使用 say"
$ SAY_VOICE=en-US-JennyNeural say "Hello there"

調整語速

帶 % 或正負號的是百分比；純數字當成 macOS 的 WPM，175 WPM 等於 +0%。拖拉看看兩種寫法怎麼對應：

$ say -r 210 "念快一點"
$ say -r +20% "效果完全一樣"

調整音調與音量

音調用 Hz，音量用百分比，都可以是負數。

$ say --pitch +10Hz --volume +15% "提高音調、放大音量"
$ say --pitch -8Hz --volume -30% "低沉一點、小聲一點"

存成音訊檔

加上 -o 就不播放，改存檔。格式依副檔名決定，支援 mp3、wav、ogg、webm。

$ say -o greeting.mp3 "這段會存成 MP3"
$ say -o notice.wav -r +10% "這段會存成 WAV"

從檔案或管線讀取

長文章會自動切段合成，再接成同一段音訊。

$ say -f article.txt
$ echo "Hello from a pipe" | say -v Ava

指定播放裝置

先列出裝置，再用編號或名稱開頭指定。

$ say -a "?"
$ say -a 0 "用第 0 號裝置播放"

邊念邊標示

-i 會在終端機裡把念到的字反白，也可以指定顏色；--progress 顯示進度條。

$ say -i "預設用反白標示"
$ say --interactive=green "改用綠色標示"
$ say --progress "顯示合成與播放進度"

給 Agent 的話

把這段提示詞貼進 AGENTS.md、CLAUDE.md 或 Agent 的自訂指令，它每完成一項任務就會用 say 念出摘要，人不在螢幕前也知道結果。Claude Code、Codex、Copilot、Cursor 這些能執行終端機指令的 Agent 都適用。

AGENTS.md 
整個任務完成、準備回覆我之前，請用 `say` 指令把這次的執行摘要念出來：
- 用一兩句話說明做了什麼、有沒有成功，以及需要我處理的事。
- 這段話是要念給人聽的，請用口語，不要念程式碼、檔案路徑或網址。
- 例如：`say "登入頁的錯誤修好了，測試全部通過。新的錯誤訊息請你確認一下。"`

全部參數

在終端機裡執行 say --help 也看得到。

參數 預設值 說明
[MESSAGE]...—要念的文字，多個參數以空白連接。沒給文字也沒指定 -f 時，改從 stdin 讀取。
-v, --voice <VOICE>zh-TW-HsiaoChenNeural語音名稱，完整 ShortName 或名稱片段都行，也可用 SAY_VOICE 環境變數設定。傳入 ? 列出所有語音。
--list-voices—列出所有語音，效果同 -v "?"。
--locale <LOCALE>—依語系前綴篩選語音清單，例如 zh-TW、en-US、ja。
-r, --rate <RATE>+0%語速。+20%、-15% 是百分比（-100 到 200）；200、120 這類純數字是 WPM，175 WPM 等於 0%。
--pitch <PITCH>+0Hz音調，例如 +10Hz、-5Hz。
--volume <VOLUME>+0%音量，例如 +20%、-30%。
-o, --output-file <FILE>—不播放，改存成音訊檔，格式依副檔名決定。
--file-format <FORMAT>依副檔名mp3、wav、ogg 或 webm。傳入 ? 列出支援的格式。
--data-format <FORMAT>—Edge TTS 原生的 audio_format 字串，例如 audio-24khz-96kbitrate-mono-mp3。傳入 ? 列出清單。
-f, --input-file <FILE>—從檔案讀取文字；- 代表 stdin。
-a, --audio-device <DEVICE>系統預設輸出裝置的編號或名稱開頭（不分大小寫）。傳入 ? 列出裝置。
--progress關閉在 stderr 顯示合成與播放進度。
-i, --interactive[=MARKUP]關閉播放時在終端機標示念到的字。可指定 bold、smul、smso、顏色名稱，或用 yellow/blue 指定前景與背景。
-h, --help—顯示說明。
-V, --version—顯示版本。
